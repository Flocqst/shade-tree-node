How it works

Each CONNECT tunnel carries a target-bound Groth16 RLN membership proof for a fresh epoch slot. A node verifies it before egress and uses epoch-scoped nullifiers to enforce its view of the member's tunnel limit. The Elder Tree serves the signed Canopy and never carries traffic.

Tor exit addresses are public, and shared traffic often trips abuse controls. Shade Tree gates each tunnel and publishes no egress-IP list. Destinations still see and can block a node IP.
