Running an agent

Run the proxy.

Launch Hermes—or another proxy-aware process—through the local proxy. It passes proxy settings only to that child; loopback model servers and the rest of the machine stay outside the route.

$ shade-tree run -- hermes

The edge of the shade

Small claims, clearly drawn.

Node sees the destination host, port, timing, and byte counts.

Destination sees the node’s public IP and can still block it.

Network Shade Tree does not prevent end-to-end timing correlation or force a node to forward honestly.

Providing cover

Run a Shade Tree node.

A node is a Tor onion service with a proof-gated CONNECT gateway. It provides destination-facing egress for admitted agents: destinations see the node’s public IP. It can run near GPU workers, model servers, or an Ethereum validator; give egress a dedicated public IP when you can.
