How it works

Reputation gate

Reputation comes from the admission policy, not the proof. Operators admit invited, staked, or paid Merkle roots. The Proxy uses Groth16 RLN to prove its rate-commitment leaf belongs to one root without revealing which leaf. Private slots yield epoch-scoped nullifiers, so each node can enforce its view of the tunnel budget.

Network path

The Proxy verifies a signed Canopy from the Elder Tree, selects a Shade Tree node, and opens a target-bound CONNECT tunnel through Tor. The node verifies the proof before making the destination-facing connection. The Elder Tree stays outside the traffic path.

Tor exit addresses are public. Shade Tree gates each tunnel and publishes no egress-IP list. Destinations still see and can block a node IP.
