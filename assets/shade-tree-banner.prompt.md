# Shade Tree banner prompt

Use case: stylized-concept

Asset type: wide GitHub README and minimal website banner

Primary request: a quiet, original visual identity for an open-source project
named Shade Tree — a small grove creating a protected patch of shade for local
machines

Scene/backdrop: warm white paper with generous negative space

Subject: three to five slender trees forming one connected canopy; beneath
them, a single calm patch of shadow; extremely subtle thread-like paths in the
roots suggest a distributed network without literal circuit icons

Style/medium: refined monochrome ink drawing with sparse woodcut and
technical-etching linework, contemporary editorial restraint, not rustic and
not fantasy

Composition/framing: very wide panoramic banner, approximately 3:1;
asymmetric grove concentrated toward the left and upper edge, shade extending
gently across the lower middle; clean breathing room

Lighting/mood: cool quiet daylight, protective but not sentimental

Color palette: near-black ink, warm paper, one restrained muted moss-green
wash only in the shade

Materials/textures: fine ink hatching, faint paper grain, crisp edges

Constraints: no text, no letters, no logos, no people, no buildings, no sun
icon, no lock/shield/hood imagery, no glossy gradients, no watermark; must
remain legible when scaled down in a GitHub README

Avoid: corporate cybersecurity illustration, generic tech-network nodes, clip
art, photorealism, dense forest, dramatic rays, neon colors
